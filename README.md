# Sistema de Gestión de Activos e Inventario

Sistema completo para la gestión de activos e inventario con interfaz web moderna y responsive.

## 📁 Estructura del Proyecto

```
Inventario/
├── frontend/          # Aplicación React + Tailwind CSS
│   ├── src/          # Código fuente de la aplicación
│   ├── public/       # Archivos públicos
│   └── README.md     # Documentación del frontend
└── README.md         # Este archivo
```

## 🚀 Frontend

La interfaz de usuario está desarrollada con:
- **React** v18
- **Tailwind CSS** v3
- **Lucide-React** para iconografía

### Características del Frontend

✅ **Layout Completo**
- Sidebar fijo con navegación
- Header con buscador y perfil de usuario

✅ **Módulos Implementados**
- Dashboard con KPIs
- Inventario (R6)
- Préstamos (R7)
- Reportar Falla (R14)
- Usuarios (R5)
- Buscador Multicriterio (R11)
- Cerrar sesión (R3)

✅ **Componentes**
- Tabla de activos moderna
- Modal de reporte de fallas
- Dropdown de acciones
- Badges de estado con colores

✅ **Diseño**
- 100% Responsive
- Paleta de colores limpia (#f9fafb)
- Fuente Inter
- Iconos de Lucide-React

### Iniciar el Frontend

```bash
cd frontend
npm install
npm start
```

Visita http://localhost:3000 para ver la aplicación.
